# Localization boundary for guard text (T7)

User-visible guard refusals are safety communication, so they are localized like
the rest of the UI, not buried as English-only literals.

## What is localized

All strings returned by the guard and the run planner that reach the UI —
`PlanCard`'s blocked label (`item.blocked`) and the cleanup-failure alert — go
through `String(localized:)` with the English copy as the key. Keys live in all
7 `app/<locale>.lproj/Localizable.strings` tables:

| Site | Strings |
|---|---|
| `CleanupGuard.blockReason(path:)` | Outside your home folder · Too broad: other apps keep live data here · In ~/%@, which AppleTree never cleans · A git repository · Managed by macOS |
| `CleanupGuard.blockReason(command:)` | AppleTree only runs tools' own cleanup commands · Command not allowed |
| `AgentRun.start` blocking reasons | Already clean · Nothing to remove · Quit %@ to clean this · Already gone · A Codex chat you used in the last 2 days · In projects you used in the last 2 days |

Interpolations use `%@` in the key (`In ~/%@, which AppleTree never cleans`,
`Quit %@ to clean this`); the locale tables translate the surrounding text and
keep the placeholder.

The 13 keys were translated mechanically as a first pass and are **marked for
review** by a native speaker; English copy is unchanged in `en.lproj`, and a
missing table entry falls back to the key itself (English), so the safety
message is never blanked.

## What is deliberately English-only

Nothing in the guard path. Reason strings the engine emits (Rust `cleanup.rs`
labels such as "npm packages, reinstallable") arrive as scan *data* through the
FFI and are shown verbatim; they are English-only by design — the single source
of truth for cleanup rules stays in Rust, and duplicating them as l10n keys
would create a second copy that can drift.

## Keeping it that way

Every `blockReason` return site must either use `String(localized:)` or carry
an `// English-only:` comment with a reason. A grep check enforces this:

```sh
grep -n 'return "' app/CleanupGuard.swift   # must return no plain-literal returns
```
